# Community

This repository is created and maintained by the [AI Security Engineers Community](https://www.aiseceng.io/), which advances the security of AI-powered and agentic applications through education, practitioner collaboration and knowledge sharing. The community runs local chapters and meetups around the world for people who build with AI and secure it.

## Take part

- Find or start a local chapter at <https://www.aiseceng.io/>.
- Improve this list: see [CONTRIBUTING.md](../CONTRIBUTING.md). Contributions from any organization or none are welcome, and the same criteria apply to everyone.
- Share an attack pattern, architecture or lesson learned by proposing a [best practice](../best-practices/README.md) edit.

## Neutrality

The community is supported by Snyk. This repository is not a sales channel. Listings carry no sponsorship weighting, proprietary products are not listed, and any entry created by the sponsor is labeled with a disclosure. If you see a violation, open a [license or neutrality concern](../.github/ISSUE_TEMPLATE/license-concern.yml).
