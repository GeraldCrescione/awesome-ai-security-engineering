## Practice safely

- Run vulnerable applications in an isolated environment, not on a shared network or a machine with real credentials.
- Use throwaway API keys with spending limits when a lab calls a hosted model.
- Learn the defensive side too: [best practices](../best-practices/README.md).

## What to read first

1. [What is AI Security Engineering?](../foundations/what-is-ai-security-engineering.md)
2. The [OWASP Top 10 for Agentic Applications](../resources/README.md#owasp-top-10-for-agentic-applications-2026) to learn the risk vocabulary.
3. [MITRE ATLAS](../resources/README.md#mitre-atlas) case studies for real attack patterns.
