# Defend

Continuously protect deployed AI-native systems, and keep a human in the loop where the consequences warrant it.

**Capabilities:** runtime observability, agent activity monitoring, behavioral anomaly detection, security policy enforcement, tool execution controls, runtime guardrails, agent identity monitoring, data exfiltration detection, AI incident response, automated remediation, security posture management, continuous validation, detection engineering, human-in-the-loop response.

**Where the open ecosystem stands:** policy engines, guardrail frameworks, an agent governance toolkit and telemetry conventions exist. Open detection content, incident response playbooks for agent compromise, and posture management have no verified open-source resource yet. Guardrail frameworks are probabilistic filters; pair them with deterministic authorization.
