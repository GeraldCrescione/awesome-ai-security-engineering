# Break

Test how AI-native systems fail under adversarial conditions, and measure it in a way you can repeat.

**Capabilities:** LLM red teaming, agentic AI red teaming, prompt injection testing (direct and indirect), agent hijacking, tool poisoning, memory and data poisoning, model extraction and inversion, adversarial ML, multi-agent attack simulation, security evaluations, reproducibility testing, vulnerability discovery benchmarks, exploit validation.

**A reminder:** this stage is one of five. Red teaming finds problems; it does not replace discovery, architecture, identity, or runtime defense. Test results from LLM-based tools are also probabilistic, so repeat runs and record variance; see [best practices](../best-practices/README.md).
