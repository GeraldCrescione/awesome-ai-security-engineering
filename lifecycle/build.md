# Build

Integrate security into AI-powered software development, and into the development of AI-powered software.

**Capabilities:** secure AI-assisted coding and vibe coding, coding agent security, dependency security, model artifact validation, AI supply chain security, AI-BOM and provenance, CI/CD integration, secure MCP implementation, agent skills security, secure RAG implementation, developer guardrails, automated security testing, secure-by-default templates.

**Where the open ecosystem stands:** sandboxing coding agents, signing and scanning model artifacts, and scanning agent skills are covered. Secure vibe-coding guardrails, AI-generated-code analysis and secure RAG implementation have no verified open-source resource yet.
