# Discover

Understand your organization's AI attack surface. You cannot threat-model, restrict or monitor what you have not found.

**Capabilities:** AI application inventory, model discovery, agent discovery, MCP server discovery, agent skill discovery, shadow AI detection, AI-BOM generation, software and model dependency mapping, data-flow visibility, sensitive data identification, AI service and API inventory, agent tool and permission inventory.

**Where the open ecosystem stands:** discovery is the thinnest stage. Only one qualifying open-source discovery tool and one inventory standard were verified. Shadow AI detection, data-flow mapping and permission inventories have no verified open-source option yet. Contributions are welcome; see [CONTRIBUTING.md](../CONTRIBUTING.md).
